지난글([[AI 서비스 8종 사용 후기|AI 서비스 8종 사용 후기]])을 작성하고서 1년 넘게 지났는데, AI를 사용하는데 있어 많은 것이 변했고, 앞으로도 변할 것 같다. 지난글이 의도치 않게 좋은 기록이 되었다고 판단되어 1년 정도 지난 지금 또 한번 정리해두려고 한다.

### Claude가 주력이 되었음

먼저 지난글의 도구를 현시점에서 정리해보면,

- Cursor는 터미널 용도로 사용하게 되었다. 다른 기능은 사용하지 않는다.
- Figma는 전혀 사용하지 않고, Meshy 대신에 Tripo를 좀 더 사용하는 것 같다.
- Midjourney도 사용하지 않으며, Perplexity 역시 사용하지 않는다.
- ChatGPT는 여전히 이미지 생성 중심인데, 클로드에서 API 키로 사용하는 것으로 변경되었다. Astra 및 기타 모델은 클로드보다 월등하다고 판단되지 않아서 사용할 생각이 안드는 것 같다. 
- Gemini는 최근 모델(Neon 등) 성능이 좋다고 하는데.............안쓴다. 신뢰를 잃어버렸음. 다른 영역으로 좀 써봐야 하는 생각은 든다. 다른 Google 제품들 때문에 유지는 해야할 것 같아서.

결론적으로 대부분 클로드로 진행하는 것으로 수렴되었다. Blender, Unity, Unreal 모두 클로드로 조작하고, 클로드로 가능한건 모두 클로드로 진행한다.

사실 웹, 앱, 게임을 주로 개발하기 때문에 그런 것 같다. 다른 분야에 집중한다면 사용하는 것들이 달라졌을 것으로 생각한다.

### Claude Desktop

Claude Code로 시작했기 때문에 터미널 환경에서 작업하는 것을 선호했고, 때문에 데스크탑앱은 사용하지 않았었다. 단순 질문할 때 빼고.

에이전틱 코딩에 신뢰를 가진 이후로 서버에 세션 열어두고 리모트로 접근하는 일이 잦았는데, 오픈소스 도구 사용하거나, ssh로 붙어서 작업하거나 했었지 데스크탑을 쓰진 않았다.

그런데 이제는 데스크탑 및 모바일 클로드를 굉장히 자주 쓴다.

remote control이 이제는 잘 작동하며, 특히 데스크탑 앱에서 터미널보다 편하게 확인할 수 있기 때문에 쓰지 않을 이유가 없다. 물론 아직 터미널에서만 되는 것들이 있는 것 같아서 완전히 터미널을 안열 수는 없는데 쓰는데 큰 불편은 없다.

최근에 CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS 을 켜서 세션 오케스트레이션 방식으로 사용하고 있는데, 이 때문에 데스크탑 및 모바일을 더 많이 사용하게 되는 것 같다.

### Ollama는 서브 용도

API로 LLM을 사용해야 하는데 크레딧 충전이 어려운 경우가 있어서 ollama를 구독해서 사용하고 있다. 클로드 정도의 신뢰는 아직 없지만, 그래도 상위 모델(Deepseek, glm 등)을 클라우드 환경에서 API로 쓸 수 있어서 잘 사용해왔다. 사용량도 넉넉해서 현재까지 큰 문제 없이 잘 사용하고 있다.

그런데 클로드가 구독형으로 다른 하네스에서도 쓸 수 있게 되고, 구독하면 API 크레딧을 충전주게 되어서 점점 애매해지고 있는 상황이긴 하다.

하지만 여전히 학생들에게 AI 쓸 수 있도록 해준다거나, 클로드 정도는 필요 없는데 API로 해야 하는 정도일 때는 넉넉하게 사용하고 있어서 당분간 유지할 생각이다.

OpenCode Go나 OpenRouter등도 있는 것 같은데 일단 Ollama 유지할 생각.

### 아직도 혼란스럽다.

여전히 하루가 멀다하고 새로운 모델, 새로운 기술이 쏟아진다. X를 보고 있으면 어지러울 정도다.

언제쯤 정리(?)가 될까라는 생각이 있는데 가까운 시일 안에는 안될 것 같다. 끝모르고 발전하는 중인 것 같아서.

혼란스러운 상황이지만 AI를 기존의 작업 흐름에 얼마나 효과적으로 통합하느냐가 중요한 건 여전한 것 같고, 누구나 더 많은 것들을 더 쉽게 할 수 있게 되어서 '의지'를 가지고 꾸준하게 프로덕션 레벨로 만들어 내는 것이 더 중요해진 것 같다.

1년 뒤에는 어떻게 될 지 감도 안온다. 1년 뒤에 또 기록해봐야 할 것 같다.
